# Building a Boltzmann Machine

A short, hands-on implementation and tutorial for Boltzmann Machines (Restricted Boltzmann Machines — RBMs — and simple Deep Boltzmann Machine examples). This repository provides PyTorch implementations, Jupyter notebooks, example datasets, training scripts, sampling/visualization utilities, and explanation notes to help you learn how energy-based generative models work in practice.

## Features
- Minimal PyTorch implementations of RBM and a simple DBM-like stack
- Jupyter notebooks that walk through theory, training, and sampling
- Scripts for training, evaluating, and visualizing learned features
- Example demos on MNIST / small synthetic datasets
- Utilities for Gibbs sampling, persistent chains, and monitoring reconstruction/error

## Quickstart

1. Clone the repo:
```bash
git clone https://github.com/lotus-outlook-6/Building-a-Boltzman-Machince.git
cd Building-a-Boltzman-Machince
```

2. Create a Python environment and install dependencies:
```bash
python -m venv venv
source venv/bin/activate     # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

3. Run a training notebook or a script:
- Open `notebooks/01-rbm-intro.ipynb` and run the cells to train an RBM on MNIST.
- Or run the example training script:
```bash
python scripts/train_rbm.py --dataset mnist --epochs 20 --hidden-size 256
```

4. Visualize samples and filters:
```bash
python scripts/sample_rbm.py --checkpoint checkpoints/rbm_epoch20.pt --num-samples 25
```

## Usage

Notebooks:
- `notebooks/01-rbm-intro.ipynb` — conceptual walkthrough and training an RBM
- `notebooks/02-sampling-and-visualization.ipynb` — sampling strategies and visualizing learned filters
- `notebooks/03-dbms-and-stacking.ipynb` — stacking RBMs and short notes on DBM behavior

Scripts:
- `scripts/train_rbm.py` — train RBM from command line, saves checkpoints to `checkpoints/`
- `scripts/sample_rbm.py` — sample from a saved RBM checkpoint and visualize results
- `scripts/evaluate_reconstruction.py` — compute reconstruction error on test data

Typical training command:
```bash
python scripts/train_rbm.py \
  --dataset mnist \
  --batch-size 128 \
  --hidden-size 256 \
  --lr 0.01 \
  --k 1 \
  --epochs 30 \
  --output checkpoints/rbm_mnist.pt
```

## Repository layout
- notebooks/               — Jupyter notebooks with explanations and walkthroughs
- src/                     — model implementations (rbm.py, dbm.py), training and utils
- scripts/                 — convenience CLI scripts for training, sampling, evaluation
- data/                    — helper code to download or preprocess small datasets
- checkpoints/             — saved model checkpoints (gitignored)
- examples/                — saved sample outputs, visualizations
- requirements.txt
- README.md

## Results and examples
See `examples/` for sample filters, reconstructions, and sampling grids generated by the notebooks. Typical RBM filters learned on MNIST are included as PNGs in `examples/filters/`.
